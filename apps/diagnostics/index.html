Камера и кадр

Камера выключена

Нажмите «Открыть камеру» для проверки доступа. Браузер может отклонить запрос без диалога разрешения.

Камера ещё не проверялась.

Техническая причина отказа

        
Если разрешение камеры не появляется
Адрес content:// означает, что браузер открыл вложение через поставщика файлов Android. Даже в Chrome и при isSecureContext=true этот способ запуска может не допускать запрос камеры.
  1. Проверьте в Android: Настройки → Приложения → Chrome → Разрешения → Камера. Если используется другой браузер, выберите его.
  2. В Chrome: Настройки → Настройки сайтов → Камера → сайтам разрешено запрашивать доступ. Проверьте также общий переключатель доступа к камере в Android.
  3. Сохранение в «Загрузки» и открытие из файлового менеджера иногда меняет способ запуска. Если в адресе остаётся content://, это не проверка с обычного сайта.
  4. Для проверки полного видеопотока нужен допускающий камеру контекст: например, этот же HTML на HTTPS или localhost на самом телефоне. HTTP по сетевому IP компьютера не заменяет безопасный контекст. Сервер может только выдавать HTML; фотографии и симуляция остаются на телефоне.
Страница не может сама выдать разрешение или гарантированно определить, запретил ли доступ пользователь, браузер, источник документа или Android. Сохраните диагностический JSON. Синтетический прогон доступен и без камеры.
